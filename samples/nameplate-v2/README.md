# 新版銘板の文字試験片

まず`NP3-LETTER-TEST-B-V2.3mf`か同じSTLの**どちらか一方を1個**使います。
65.4×30.9×3.6 mm、黒2.4 mm＋白1.2 mm。mm・100%、平らな裏面を下、文字を上。
汎用3MFは未スライスで、Pause・実機profile・G-codeを含みません。

実際の新版から`icon, New ad`と`b.com/to`を、文字倍率と行内の字間を変えず切り出しています。
孔・eの開口・字間・点・スラッシュ・mの接合を、実装ノズルと一致する0.2 mm設定で確認します。
黒2.4 mmの終了後、最初の白い経路より前にPauseを設定してください。固定層番号はありません。

これは完成BOM150個とは別の試作です。取付けキーがなく、大きい銘板の反り・保持・嵌合試験は代行しません。
詳しくは[変更説明](../../docs/NAMEPLATE-V2.md)と[印刷手順](../../docs/PRINTING.md)を参照してください。
