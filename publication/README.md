# 公開範囲とGitHub Pages

2026-09-23、ユーザーから個人向けリポジトリ全体のpublic化と、
本人へ説明・作り方・工程を見せるGitHub Pagesの公開を明示的に承認されました。
以前の「private／Pagesなし」方針はこの承認で更新しています。

リポジトリの現在の追跡ファイルとGit履歴は公開されます。
切替前に、実際にremoteへ公開されるmainの5コミット・368 blobと、
ZIP／3MF／native内部を含む569件の内容を点検しました。
認証情報・絶対ローカルパス・加工前写真・元パス監査表・画像EXIFは検出されませんでした。
個人銘板と許可済み写真は意図した公開内容であり、秘密として誤分類していません。

`.work`、未追跡の私有フォルダ、セッション状態、ローカルのCopilot checkpoint refsは、
このリポジトリの公開ブランチへpushしていません。履歴を削除・書き換える作業でもありません。
公開された内容は第三者にコピー・cacheされ得るため、削除で完全回収できる保証はありません。

Pagesは公開用の出力だけをアップロードします。リポジトリのルートをそのまま配信しません。
原写真、EXIF、認証情報、監査元パス、内部検証記録、nativeの一式、旧版・旧履歴は、
Pagesの配信フォルダに含めません。印刷データは公開repoの対応ファイルへリンクします。

模型の寸法、100%の印刷倍率、150配置は今回変更していません。
この作業は公開のための案内と配信設定の変更で、形状・表示・工程進捗の縮小ではありません。

[公開方針](policy.json)に、公開許可と除外範囲を記録しています。
