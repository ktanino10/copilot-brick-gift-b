# B DESK CLASSIC — 個人向け印刷・組立キット

**通常GitHub CopilotのB・1種類だけ。個人銘板入りのデータと日本語の作り方です。**
承認済みの顔、シアンのゴーグル、マゼンタの外周、緑の目、5段の黒台座を変更していません。
別PCでも、この非公開リポジトリから保存して作業できます。GitHub Pagesは使いません。

**[B全キットをダウンロード](https://github.com/ktanino10/copilot-brick-gift-b/blob/main/downloads/B-personal-print-kit.zip)**

GitHubへログイン後、リンク先で **Download raw file** → ZIPを展開。
リポジトリ上部の **Code → Download ZIP** でも同じ内容を受け取れます。
2つとも保存する必要はありません。

![個人銘板入りの承認済みB。実STLから作成した保存済みの完成配置画像](docs/images/B-hero.png)

これは実STL由来のデジタル完成図で、実物写真ではありません。
**すべてNOT_SLICED（未スライス）。実機の嵌合・保持・強度・転倒は未試験です。**
3MFは形状と配置のみで、検証済みP1S設定・Pause・G-codeを含みません。

## まず、ここから

1. **[別PCでの保存・Bambu Studio・印刷手順](docs/PRINTING.md)** を開き、
   P1Sの実ノズル・PLA・プレートとStudio設定を合わせます。
2. 最初は **[FIT-M-D470](kit/fit/FIT-M-D470.stl)＋[FIT-F-CP12](kit/fit/FIT-F-CP12.stl)を各1個だけ**。
   mm・100%・向きを確認し、スライス後に穴入口と屋根の経路を見ます。
3. **[少量試作の順番](docs/TRIAL.md)** に沿い、必要なキー溝試験片 → 実ブロック4個 →
   keeperとB台座端部3個 → 実5段台座・前面 → 顔の少量バッチへ進みます。
4. 問題がなければ **[組立・銘板交換・分解](docs/ASSEMBLY.md)** と
   **[28工程の図](docs/STEPS.md)** を見ながら組みます。

**穴・溝が塞がる、指でつかめない、座らない、強い力が必要、割れ、保持不足があれば停止。**
全数を先に刷らず、穴を1つずつ削る・工具で無理押しすることを前提にしません。
試作7個の成功だけでは完成品の合格になりません。

## 色とファイルの選び方

必要なPLAは**黒・シアン・マゼンタ・緑・白の5色**。
平らな机、柔らかい布、色／部品ID別のトレー、観察用のノギスを用意します。
接着剤・別ピン・ハンマーは不要です。

| 印刷するもの | 組込数 | 3MF候補配置 | ノズルの出発点 |
|---|---:|---:|---|
| 黒い本体・台座・keeper | 82 | 黒7枚 | 0.4 mm |
| シアン | 36 | シアン2枚 | 0.4 mm |
| マゼンタ | 22 | マゼンタ2枚 | 0.4 mm |
| 緑 | 8 | 緑1枚 | 0.4 mm |
| 個人銘板 | 1 | 黒→白1枚、支持体2.4 mm後 | 0.2 mm |
| 右ロゴ | 1 | 黒→白1枚、支持体2.8 mm後 | 0.2 mm |
| **合計** | **150** | **14枚** | **いずれも未実機検証** |

BOMの黒84個には、黒い支持体を持つ銘板とロゴ各1個も含まれます。
白のレリーフを別部品として足しません。

**[ファイル名・プレートごとの個数・STL一覧](docs/FILES.md)** から選びます。
本体4色は別々の単色プレートで印刷します。白い文字・ロゴは独立小部品ではなく、
黒い支持体とつながったレリーフです。この2部品だけ、実スライスのプレビューで
**黒地終了後／最初の白い経路の前にPauseを追加**し、P1S標準手順で手動交換します。
AMS不要の経路ですが、Pause・交換・再開は実機で未確認です。
固定の層番号や未検証G-codeは提供しません。

**STLと3MFは代替です。同じ部品の両方を読み込まないでください。**
3MFを1つ開くたびに空のプロジェクトから始めます。
ノズル0.4／0.2 mmは推奨の出発点で、現在の装着径・PLA銘柄・プレート・プロファイルを
この配布物から推測しません。時間・重量は本人の実スライス結果だけを記録します。
